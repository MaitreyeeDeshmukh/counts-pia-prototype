# Counts (PIA prototype, v1)

Prototype for the Principled Innovation Academy "Articulating Skills" challenge, Team 11.

Counts helps students catch the skills they build through work and life in their own words, and routes skill gaps to ASU resources.

Open `index.html` in a browser. Tap "Load a sample semester" to see it filled in with a made up student.

This is the version before adding "learning" (class and project) capture.
