# Counts (PIA prototype)

Prototype for the Principled Innovation Academy "Articulating Skills" challenge, Team 11 (Maitreyee, Larissa, Lois).

Counts asks one short question right after class, after a shift, or about life and unpaid work, keeps the student's own words, and names the skills inside them. When a skill is missing for their major, it routes them to an ASU resource.

Open `index.html` in a browser. Tap "Load a sample semester" to see it filled in with a made up student.

## What's in it
- After class, after a shift, and life capture, voice or typing
- Skills named with the student's exact quote kept beside them, plus specific techniques and tools they named
- Manager writes one line, and skill swap with a classmate
- ASU resource routing by skill gap, eligibility aware
- Deadline mode, interview practice and posting matching
- Instructor and ASU view, counts only, no names or stories

## Notes
- Data is stored in the viewer's own browser only
- The reminder, manager link and classmate swap are simulated in this prototype
- Instructor numbers are sample data
- ASU resource list checked against ASU web pages in September 2026
