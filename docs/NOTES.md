# Notes

## What is real in this prototype

- Capture after class, after a shift, and for life or unpaid work
- Skill naming, with the student's exact quote and a reason for each skill
- Editing and removing suggested skills before saving
- The story bank, evidence lines, and Situation / Action / Result practice
- ASU resource matching by skill, including eligibility (some resources are
  only open to students on the ASU payroll)
- Deadline mode: interview practice and matching stories to a posting

## What is simulated

- The end of shift or end of class reminder. The app previews it, it does not send it.
- The manager one line link. The manager side is shown as a preview on the same device.
- The classmate skill swap. Both sides run on one device.
- The instructor and ASU view. The class numbers are sample data, clearly labelled
  in the interface. Only the current student's own counts are real, and only if
  they opted in.

## Skill naming

Two paths:

1. **Claude**, when the page is running somewhere it is available. The prompt
   forbids inventing facts and requires an exact quote per skill.
2. **Offline keyword pass**, otherwise. It matches phrases in the student's own
   sentences and quotes the matching fragment. Less precise, never invents.

Named techniques (for example a lab method a student mentions) are picked up and
shown separately from the soft skills.
